# vecho 자세한 설명서

짧은 안내는 [README](../README.md)에 있습니다. 여기서는 하나하나 자세히 설명합니다.

**대화를 녹음하면, 누가 무슨 말을 했는지 글로 적어 주고 중요한 내용을 정리해 주는 프로그램입니다.**

회의, 화상 통화(줌·디스코드·구글 미트 등), 상담, 수업, 면담… 컴퓨터로 하는 대화라면 무엇이든 됩니다.

- **무료**입니다.
- 모든 일이 **내 컴퓨터 안에서만** 이루어집니다. 목소리와 대화 내용이 인터넷으로 나가지 않습니다.
- 녹음을 멈추면 **요약**(한 줄 요약, 핵심 내용, 정해진 일, 할 일)과 **대화 기록**이 저절로 만들어집니다.

## 1. 내 컴퓨터에서 쓸 수 있는지 확인하기

### Mac

화면 맨 왼쪽 위의 **사과 모양()** 을 누르고 **이 Mac에 관하여**를 누르세요. 창이 하나 뜹니다.

| 창에 보이는 항목 | 이렇게 쓰여 있으면 됩니다 |
| --- | --- |
| **칩** | `Apple M1`, `M2`, `M3`, `M4` … (가장 좋습니다) <br> `Intel`이라고 쓰여 있어도 쓸 수 있지만 정리하는 데 시간이 훨씬 오래 걸립니다. |
| **macOS** | **13** 이상 (이름으로는 Ventura, Sonoma, Sequoia, Tahoe) <br> 상대방 목소리까지 녹음하려면 **14.4** 이상이어야 합니다. |
| **메모리** | **8GB** 이상 (클수록 요약이 좋아집니다. 아래 표 참고) |

### Windows (시험판)

**시작 버튼** → **설정**(톱니바퀴) → **시스템** → **정보**를 누르세요.

| 항목 | 이렇게 쓰여 있으면 됩니다 |
| --- | --- |
| **에디션** | Windows 10 또는 Windows 11 |
| **설치된 RAM** | **8GB** 이상 |

> Windows 버전은 아직 시험판입니다. 문제가 생길 수 있어요.

### 공통

- **인터넷은 설치할 때만** 필요합니다. 설치가 끝나면 인터넷 없이도 씁니다.
- 메모리 크기에 맞는 요약 AI가 **자동으로** 설치되니, 따로 고를 것은 없습니다.

| 컴퓨터 메모리 | 설치되는 요약 AI | 필요한 저장 공간 | 요약 품질 |
| --- | --- | --- | --- |
| 32GB 이상 | qwen3.8:27b | 약 25GB | 가장 좋음 |
| 16GB 이상 | qwen3:8b | 약 10GB | 좋음 |
| 16GB 미만 | qwen3:4b | 약 7GB | 기본 |

(저장 공간에는 모든 컴퓨터에 똑같이 설치되는 음성 인식 AI 약 1.5GB와 프로그램이 포함됩니다.)

## 2. 설치하기 (처음 한 번만)

설치는 **글 한 줄을 붙여 넣는 것**으로 끝납니다. 나머지는 프로그램이 알아서 합니다.

### Mac

**① '터미널'을 엽니다.** (명령을 입력하는 창입니다. 겁먹지 않으셔도 됩니다.)

키보드에서 `⌘ command` 키를 누른 채로 `스페이스바`를 누르세요. 화면 가운데에 검색 칸이 나타나면
`터미널`이라고 입력하고 `return` 키를 누르세요. 글자가 적힌 작은 창이 열립니다.

**② 아래 회색 상자 속 글을 복사합니다.**

회색 상자 위에 마우스를 올리면 상자 오른쪽 위에 **종이 두 장이 겹친 모양의 버튼**이 나타납니다. 그 버튼을 누르면 복사됩니다.

```
curl -fsSL https://raw.githubusercontent.com/Nhahan/vecho/main/install.sh | sh
```

**③ 터미널 창을 한 번 누른 뒤 `⌘ command` + `V` 를 눌러 붙여 넣고, `return` 키를 누릅니다.**

붙여 넣기만 하면 아무 일도 일어나지 않습니다. 꼭 `return` 키를 눌러 주세요.

**④ 기다립니다.**

글자가 계속 올라가며 필요한 것들을 설치하고, AI를 내려받습니다(진행 막대가 보입니다).
인터넷 속도에 따라 **10분에서 1시간 정도** 걸립니다. 그동안 **터미널 창을 닫지 마세요.**
중간에 **Ollama**라는 창이 뜨면 그냥 닫아도 됩니다. (요약을 맡는 AI 프로그램입니다.)

맨 아래에 **`준비가 끝났습니다!`** 라는 글이 나오면 설치가 끝난 것입니다. 이제 터미널 창을 닫아도 됩니다.

### Windows

**① 'PowerShell'을 엽니다.** (명령을 입력하는 창입니다.)

화면 아래의 **시작 버튼**(창문 모양)을 누르고 `PowerShell`이라고 입력한 뒤 `Enter` 키를 누르세요.
글자가 적힌 창이 열립니다.

**② 아래 회색 상자 속 글을 복사합니다.** (상자 오른쪽 위의 복사 버튼을 누르세요.)

```
irm https://raw.githubusercontent.com/Nhahan/vecho/main/install.ps1 | iex
```

**③ PowerShell 창에서 마우스 오른쪽 버튼을 누르거나 `Ctrl` + `V` 를 눌러 붙여 넣고, `Enter` 키를 누릅니다.**

**④ 기다립니다.** 맨 아래에 **`준비가 끝났습니다!`** 라는 글이 나오면 끝입니다. 이제 창을 닫아도 됩니다.

### 설치하다가 문제가 생기면

- **빨간 글자가 나오고 멈췄다면:** 인터넷이 연결되어 있는지 확인한 뒤, 같은 글을 **한 번 더 붙여 넣고 실행**하세요.
  여러 번 실행해도 괜찮습니다. 이미 설치된 것은 건너뜁니다.
- **그래도 안 된다면:** 화면을 사진으로 찍어 [여기](https://github.com/Nhahan/vecho/issues)에 남겨 주세요.

## 3. 실행하기

### Mac

- **Finder**(웃는 얼굴 아이콘)를 열고 왼쪽의 **응용 프로그램**을 누른 뒤, **vecho**를 두 번 누르세요.
- 또는 `⌘ command` + `스페이스바`를 누르고 `vecho`를 입력한 뒤 `return` 키를 눌러도 됩니다.

**자주 쓴다면:** vecho가 켜져 있을 때 화면 아래쪽(Dock)의 vecho 아이콘을 마우스 오른쪽 버튼으로 누르고
**옵션 → Dock에 유지**를 고르세요. 다음부터는 Dock에서 한 번 눌러 바로 켤 수 있습니다.

### Windows

바탕 화면의 **vecho** 아이콘을 두 번 누르세요. (시작 메뉴에도 있습니다.)

## 4. 처음 녹음할 때: '허용' 누르기

처음 녹음을 시작하면, 컴퓨터가 "vecho가 이것을 써도 될까요?" 하고 묻는 창을 띄웁니다. **모두 '허용'을 눌러 주세요.**

- **마이크** — 내 목소리를 녹음하려면 필요합니다.
- **시스템 오디오 녹음** (Mac) — 상대방 목소리(컴퓨터 스피커나 이어폰으로 나오는 소리)를 녹음하려면 필요합니다.

**실수로 '허용 안 함'을 눌렀다면 (Mac):**
1. 화면 왼쪽 위 **사과 모양()** → **시스템 설정**을 누릅니다.
2. 왼쪽에서 **개인정보 보호 및 보안**을 누릅니다.
3. **마이크**를 눌러 목록에서 **vecho** 옆의 스위치를 켭니다.
4. 뒤로 돌아가 **화면 및 시스템 오디오 녹음**을 눌러 **vecho**를 켭니다.
   (macOS 버전에 따라 항목 이름이 조금 다를 수 있습니다.)

**Windows에서 내 목소리가 녹음되지 않는다면:**
**시작 버튼** → **설정** → **개인 정보 및 보안** → **마이크**에서 **마이크 액세스**와
**데스크톱 앱이 마이크에 액세스하도록 허용**을 켜 주세요.

## 5. 사용하기

1. 빨간 **녹음 시작** 버튼을 누릅니다. (제목은 적지 않아도 됩니다.)
   바로 아래 **상대방 소리도 녹음** 스위치는 켜 두세요. 꺼져 있으면 내 목소리만 녹음됩니다.
2. 평소처럼 대화합니다. 화상 통화라면 줌이나 디스코드 같은 통화 프로그램을 그대로 쓰면 됩니다.
   녹음 중에는 왼쪽 위에 **녹음 중**이라는 표시와 함께 내 목소리, 상대방 목소리가 움직이는 막대로 보입니다.
3. 대화가 끝나면 **중지하고 정리하기**를 누릅니다.

잠시 기다리면 **요약**과 **대화** 기록이 나타납니다. 녹음이 길수록 오래 걸립니다.
(1시간 녹음이면 보통 몇 분, 메모리가 작은 컴퓨터는 더 걸립니다. 그동안 다른 일을 하셔도 됩니다.)

![대화 기록 화면 — 누가 언제 무슨 말을 했는지 보이고, 시간을 누르면 그 부분부터 다시 들을 수 있습니다](transcript.png)

### 이런 것도 할 수 있어요

- **지난 대화 보기:** 왼쪽 목록에서 고르세요. 위쪽 검색 칸에 낱말을 적어 찾을 수도 있습니다.
- **다시 듣기:** **대화** 탭에서 시간(예: `12:30`)을 누르면 그 부분부터 들립니다.
- **제목 바꾸기:** 큰 제목 글자를 누르고 고쳐 쓴 뒤 `return`(`Enter`) 키를 누르세요.
- **다른 곳에 옮기기:** 요약 위의 **복사** 버튼을 누르면 메모장이나 메신저에 붙여 넣을 수 있고,
  **내보내기**를 누르면 파일로 저장됩니다.
- **내가 쓰던 양식대로 정리:** 왼쪽 위 **vecho** 글자 옆의 첫 번째 아이콘(마우스를 올리면 '요약 템플릿'이라고 나옵니다)을 누르고,
  **새 템플릿**에 예전에 쓰던 회의록이나 노트를 그대로 붙여 넣어 저장하세요.
  그다음 녹음 시작 버튼 아래의 **요약 틀**에서 그 양식을 고르면, 그 모양 그대로 정리해 줍니다. 대화에 없는 칸은 비워 둡니다.
- **휴대폰 녹음 파일 정리:** 휴대폰으로 녹음한 파일(mp3, m4a 등)을 컴퓨터로 옮긴 뒤 vecho 창에 끌어다 놓으면 정리해 줍니다.

> **팁:** 통화할 때 **이어폰**을 쓰면 내 목소리와 상대방 목소리가 가장 깨끗하게 나뉘어 녹음됩니다.

## 6. 새 버전으로 바꾸기 · 지우기

**새 버전으로 바꾸기:** [설치하기](#2-설치하기-처음-한-번만)의 글을 **한 번 더** 붙여 넣고 실행하면 됩니다.
지금까지의 녹음은 그대로 남습니다.

**지우기:** 설치할 때처럼 터미널(Mac) 또는 PowerShell(Windows)을 열고, 아래 글을 붙여 넣은 뒤 `return`(`Enter`) 키를 누르세요.

Mac:

```
curl -fsSL https://raw.githubusercontent.com/Nhahan/vecho/main/uninstall.sh | sh
```

Windows:

```
irm https://raw.githubusercontent.com/Nhahan/vecho/main/uninstall.ps1 | iex
```

녹음은 지워지지 않고 남습니다. 녹음까지 지우는 방법과 요약 AI(Ollama)를 지우는 방법은 그 창에 안내됩니다.

## 7. 자주 묻는 질문

**대화 내용이 인터넷으로 나가나요?**
아니요. 녹음, 글로 옮기기, 요약이 모두 내 컴퓨터 안에서 이루어집니다.

**돈이 드나요?**
아니요. 무료이고, 가입도 필요 없습니다.

**상대방 목소리가 녹음되지 않아요.**
Mac이라면 위의 [허용 누르기](#4-처음-녹음할-때-허용-누르기)에서 **화면 및 시스템 오디오 녹음**에 vecho가 켜져 있는지 확인하세요.
macOS가 14.4보다 낮으면 상대방 목소리는 녹음되지 않고 내 목소리만 녹음됩니다.

**화면에 '확인 필요'라고 나와요.**
그 글자를 누르면 무엇이 문제인지, 어떻게 고치는지 쉬운 말로 나옵니다. 고친 다음 **다시 확인**을 누르세요.

**정리가 너무 오래 걸려요.**
컴퓨터 메모리가 작거나 녹음이 길면 오래 걸립니다. 기다리는 동안 vecho를 닫지 말고 다른 일을 하셔도 됩니다.
처음 한 번은 AI를 준비하느라 더 걸립니다.

**글로 옮긴 내용이 틀려요.**
AI가 잘못 알아들을 수 있습니다. 시끄러운 곳보다 조용한 곳에서, 이어폰을 쓰면 더 정확해집니다.
중요한 내용은 **대화** 탭에서 그 부분을 다시 들어 확인하세요.

**한국어 말고 다른 말도 되나요?**
네. 영어 등 여러 언어를 알아서 알아듣습니다. 요약은 한국어로 정리됩니다.

**전화 통화도 녹음되나요?**
컴퓨터로 하는 통화(카카오톡 PC 통화, 줌 등)는 됩니다. 휴대폰 통화는 휴대폰으로 녹음한 파일을 vecho 창에 끌어다 놓으세요.

**녹음 파일은 어디에 있나요?**
보통은 vecho 안에서 보고 들으면 됩니다. 원래 녹음 파일이 꼭 필요하다면:
- Mac: Finder에서 `⌘ command` + `shift` + `G` 를 누르고 `~/.vecho/sessions` 를 붙여 넣은 뒤 `return` 키를 누르세요.
- Windows: 파일 탐색기 위쪽 주소 칸에 `%USERPROFILE%\.vecho\sessions` 를 붙여 넣고 `Enter` 키를 누르세요.

## 꼭 알아 두세요

- **녹음하기 전에 상대방에게 알려 주세요.** 상대방 몰래 녹음하면 문제가 될 수 있습니다.
- AI가 잘못 알아듣거나 잘못 정리할 수 있습니다. 중요한 내용은 직접 다시 확인하세요.
