# vecho

대화를 녹음하면 **글로 적고, 요약해 줍니다.**
무료이고, 모든 처리가 **내 컴퓨터 안에서만** 이루어집니다.

![vecho](docs/summary.png)

## 설치

**Mac** — `터미널`을 열고(⌘+스페이스 → "터미널") 아래 줄을 붙여 넣은 뒤 `return`

```
curl -fsSL https://raw.githubusercontent.com/Nhahan/vecho/main/install.sh | sh
```

**Windows** — `PowerShell`을 열고(시작 → "PowerShell") 아래 줄을 붙여 넣은 뒤 `Enter`

```
irm https://raw.githubusercontent.com/Nhahan/vecho/main/install.ps1 | iex
```

**`준비가 끝났습니다!`** 가 나올 때까지 기다리면 끝입니다. (처음엔 AI를 내려받느라 10분~1시간)
컴퓨터에 맞는 AI는 알아서 골라 설치합니다.

## 사용

1. **vecho**를 엽니다. (Mac: 응용 프로그램 폴더 · Windows: 바탕 화면)
2. **녹음 시작** → 대화 → **중지하고 정리하기**
3. 처음 한 번 뜨는 **마이크 / 시스템 오디오 녹음** 창에서 **허용**

## 업데이트 · 삭제

- 업데이트: 설치 줄을 한 번 더 실행
- 삭제: 위 줄에서 `install`을 `uninstall`로 바꿔 실행 (녹음은 남습니다)
