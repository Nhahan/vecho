# vecho

**대화를 녹음하면, 누가 무슨 말을 했는지 글로 적고 중요한 내용을 정리해 주는 프로그램입니다.**

회의, 전화, 화상 통화(줌·디스코드 등), 상담, 수업, 멘토링… 어떤 대화든 됩니다.
모든 일이 **내 컴퓨터 안에서만** 이루어져서 목소리와 대화 내용이 인터넷으로 나가지 않습니다. 무료입니다.

![요약 화면](docs/summary.png)

---

## 무엇이 필요한가요?

| | Mac | Windows (시험판) |
| --- | --- | --- |
| 컴퓨터 | Apple 칩(M1 이상) Mac 권장 | Windows 10 또는 11 |
| 운영체제 | macOS 13 이상 (상대방 소리 녹음은 macOS 14.4 이상) | |
| 메모리 | 8GB 이상 (16GB 이상이면 더 좋은 요약) | 8GB 이상 |
| 저장 공간 | 여유 공간 25GB 정도 | 여유 공간 25GB 정도 |

설치할 때만 인터넷이 필요합니다. 컴퓨터 메모리에 맞는 AI가 자동으로 골라집니다.

---

## 설치하기 (처음 한 번만)

### Mac

1. **터미널을 엽니다.**
   키보드에서 `command(⌘)` 키를 누른 채 `스페이스바`를 누르고, `터미널`이라고 입력한 뒤 `return` 키를 누르세요.
   글자를 입력하는 검은(또는 흰) 창이 열립니다.

2. **아래 회색 상자의 글을 그대로 복사해서 터미널에 붙여 넣고 `return` 키를 누릅니다.**
   (상자 오른쪽 위의 복사 버튼을 누른 뒤, 터미널에서 `⌘` + `V` 를 누르면 붙여 넣어집니다.)

   ```
   curl -fsSL https://raw.githubusercontent.com/Nhahan/vecho/main/install.sh | sh
   ```

3. **기다립니다.** 필요한 것들을 알아서 설치하고 AI를 내려받습니다.
   인터넷 속도에 따라 **10분에서 1시간 정도** 걸립니다. 창을 닫지 마세요.
   `준비가 끝났습니다!` 라는 글이 나오면 끝입니다. 이제 터미널 창은 닫아도 됩니다.

### Windows

1. **PowerShell을 엽니다.**
   화면 아래 **시작 버튼**을 누르고 `PowerShell`이라고 입력한 뒤 `Enter` 키를 누르세요.

2. **아래 회색 상자의 글을 복사해서 붙여 넣고 `Enter` 키를 누릅니다.**
   (PowerShell 창 안에서 **마우스 오른쪽 버튼**을 누르면 붙여 넣어집니다.)

   ```
   irm https://raw.githubusercontent.com/Nhahan/vecho/main/install.ps1 | iex
   ```

3. **기다립니다.** `준비가 끝났습니다!` 라는 글이 나오면 끝입니다.

> Windows 버전은 아직 시험판이라 문제가 생길 수 있습니다. 문제가 있으면 [여기](https://github.com/Nhahan/vecho/issues)에 알려 주세요.

## 실행하기

- **Mac:** **Launchpad**(또는 Finder → **응용 프로그램**)에서 **vecho** 아이콘을 누르세요.
  자주 쓴다면 실행 중일 때 아래쪽 Dock의 아이콘을 마우스 오른쪽 버튼으로 누르고 **옵션 → Dock에 유지**를 고르면 편합니다.
- **Windows:** 바탕 화면이나 시작 메뉴의 **vecho** 아이콘을 누르세요.

### 처음 녹음할 때 한 번만: 허용 누르기

처음 녹음을 시작하면 컴퓨터가 허락을 구하는 창이 뜹니다. **모두 '허용'을 눌러 주세요.**

- **마이크** — 내 목소리를 녹음하려면 필요합니다.
- **시스템 오디오 녹음** (Mac) — 상대방 목소리(컴퓨터 스피커로 나오는 소리)를 녹음하려면 필요합니다.

실수로 '허용 안 함'을 눌렀다면: **시스템 설정 → 개인정보 보호 및 보안**에서
**마이크**, **화면 및 시스템 오디오 녹음** 항목에 들어가 **vecho**를 켜 주세요.

## 사용하기

1. 빨간 **녹음 시작** 버튼을 누릅니다.
2. 평소처럼 대화합니다. 전화·화상 통화라면 통화 앱을 그대로 쓰면 됩니다.
3. 대화가 끝나면 **중지하고 요약하기**를 누릅니다.

잠시 기다리면 **요약**(한 줄 요약, 핵심 내용, 결정된 일, 할 일)과 **대화** 기록(누가 언제 무슨 말을 했는지)이 나타납니다.
녹음이 길수록 오래 걸립니다(1시간 녹음이면 몇 분 정도).

![대화 기록 화면](docs/transcript.png)

### 이런 것도 됩니다

- **지난 대화 다시 보기:** 왼쪽 목록에서 고르거나 위쪽 검색 칸에 낱말을 입력하세요.
- **다시 듣기:** **대화** 탭에서 시간을 누르면 그 부분부터 재생됩니다.
- **제목 바꾸기:** 제목 글자를 누르고 고쳐 쓰세요.
- **복사하기·저장하기:** 요약 위의 **복사**, **내보내기** 버튼을 누르세요.
- **원하는 양식으로 정리:** 왼쪽 위 **템플릿** 버튼에서 예전에 쓰던 회의록이나 노트를 붙여 넣으면,
  그 양식 그대로 요약해 줍니다. 대화에 없는 칸은 비워 둡니다.
- **녹음 파일 요약:** 휴대폰 녹음 파일(mp3, m4a 등)을 창에 끌어다 놓으면 바로 정리해 줍니다.

> **팁:** 통화할 때 **이어폰**을 쓰면 가장 깨끗하게 녹음됩니다.

## 자주 묻는 질문

**대화 내용이 인터넷으로 나가나요?**
아니요. 녹음, 글로 옮기기, 요약이 모두 내 컴퓨터 안에서 이루어집니다.

**돈이 드나요?**
아니요. 무료입니다.

**상대방 목소리가 녹음되지 않아요.**
Mac이라면 **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 **vecho**가 켜져 있는지 확인하세요.
macOS 14.4보다 오래된 Mac에서는 상대방 소리를 녹음할 수 없습니다.

**프로그램 화면에 '확인 필요'라고 나와요.**
그 글자를 누르면 무엇이 문제인지와 해결 방법이 나옵니다. 고친 뒤 **다시 확인**을 누르세요.

**녹음 파일은 어디에 있나요?**
- Mac: Finder에서 `⌘` + `shift` + `G` 를 누르고 `~/.vecho/sessions` 를 입력하세요.
- Windows: 파일 탐색기 주소 창에 `%USERPROFILE%\.vecho\sessions` 를 입력하세요.

**새 버전으로 업데이트하려면?**
설치할 때 쓴 명령을 한 번 더 실행하면 됩니다. 녹음은 그대로 남아 있습니다.

**지우고 싶어요.**
- Mac: 터미널에 `uv tool uninstall vecho` 를 입력하고, **응용 프로그램** 폴더(홈 폴더 안)의 **vecho**를 휴지통에 버리세요.
- Windows: PowerShell에 `uv tool uninstall vecho` 를 입력하고, 바탕 화면의 **vecho** 아이콘을 지우세요.
- 녹음까지 모두 지우려면 위의 녹음 폴더(`.vecho`)도 지우세요. 요약 AI(Ollama)는 따로 설치된 프로그램이라 원하면 따로 지우면 됩니다.

## 알아 두세요

- **녹음하기 전에 상대방에게 알려 주세요.** 상대방 동의 없이 녹음하면 문제가 될 수 있습니다.
- AI가 잘못 알아듣거나 잘못 정리할 수 있습니다. 중요한 내용은 **대화** 탭의 기록과 녹음을 직접 확인하세요.

### English

vecho records both sides of a conversation (your microphone and your computer's sound), then
transcribes and summarizes it entirely on your computer. Install on a Mac (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/Nhahan/vecho/main/install.sh | sh
```

or on Windows (PowerShell, preview):

```
irm https://raw.githubusercontent.com/Nhahan/vecho/main/install.ps1 | iex
```

Then open **vecho** from Applications / the Start menu. License: [MIT](LICENSE).
